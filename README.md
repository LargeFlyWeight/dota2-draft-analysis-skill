# dota-draft — Dota 2 draft & pro-match analyst skill for Claude

Кидаешь скрин пик-фазы в чат Claude — получаешь, кто на какой позиции, как стоят лайны,
тайминги, план на игру и подсказки на пик. Данные берутся **по текущему патчу**: скилл каждый
раз сам ищет актуальную версию патча и мету (Dota2ProTracker, Dotabuff, Liquipedia,
сайты на базе OpenDota), а не опирается на устаревшую память модели.

> English summary below.

## Возможности

- **Быстрый режим** `/dota-draft-fast` — для живой пик-фазы (также включается сам, если
  драфт на скрине ещё не закончен). 1–2 поиска, ответ в 5 строк: три варианта пика на твой слот
  и главная угроза у врага.
- **Полный разбор** — когда драфт закрыт. Патч, позиции 1–5 и роль каждого героя в этом драфте,
  лайны, тайминги и win conditions обеих команд, угрозы для твоей команды, вердикт и источники.
- **Аналитика про-матчей** — отдельной командой `/dota-draft-pro`: составы и стендины, форма команд
  (особенно на текущем патче), личные встречи, коронные герои игроков и попал ли игрок
  на свой комфорт-пик, ключевые дуэли и вердикт с уровнем уверенности. Если дать коэффициенты букмекера —
  переведёт их в вероятности и сравнит со своим анализом (без советов, на что ставить).
  Каждый ответ заканчивается дисклеймером про ставки. На пабном скрине
  с никами проверяет открытые профили игроков (только игровая статистика).
- Распознаёт героев со скриншота; если портрет нечитаемый, помечает героя знаком «(?)», а не выдумывает.
- Не придумывает винрейты: если цифру не нашёл, описывает матчап словами.
- Отвечает на языке пользователя.

## Установка

### claude.ai (браузер, десктоп-приложение)

Нужны выполнение кода и веб-поиск (оба включаются в настройках).

1. Скачай `dota-draft.zip` со страницы [Releases](../../releases) — не распаковывай.
2. Открой **Customize → Skills** → **«+» → Create skill → Upload a skill** и выбери zip.
3. Проверь, что переключатель у dota-draft включён.

Если обновляешь — сначала удали старую версию dota-draft.

### Claude Code

```bash
git clone https://github.com/YOUR_GITHUB_USERNAME/dota-draft.git ~/.claude/skills/dota-draft
```

### Структура

Репозиторий — это и есть папка скилла: `SKILL.md` в корне, режим про-матчей в
`references/match-analysis.md`. Zip для claude.ai собирается автоматически при публикации
релиза (`.github/workflows/release.yml`); вручную: из папки над репо выполнить
`zip -r dota-draft.zip dota-draft -x "dota-draft/.git/*"`.

## Как пользоваться

Команду пишешь текстом в начале сообщения, скрин прикладываешь к нему же.

| Команда | Когда | Что получишь |
|---|---|---|
| `/dota-draft-fast` + скрин | Пик-фаза, драфт не закончен | 3 пика на твой слот + главная угроза (5 строк) |
| `/dota-draft` + скрин | Драфт закрыт, стратегия / загрузка | Позиции, лайны, тайминги, угрозы, вердикт |
| `/dota-draft` + текст | До игры: «мой пул X, Y, Z — кого пикать против меты?» | Заготовки контрпиков |
| `/dota-draft-pro` + скрин или «Team A vs Team B» | Про-матч / турнир | Составы, форма, личные встречи, коронки игроков, дуэли, вердикт |
| `/dota-draft-pro быстро` | Про-матч, мало времени | Только форма, игроки и вердикт |
| `/dota-draft-pro` + пабный скрин с никами | Паб | Коронки и форма игроков с открытыми профилями |

Аналитика про-матчей запускается **только** командой `/dota-draft-pro` — она долгая, и скилл
не включает её сам. Если скилл не подхватился — напиши «используй dota-draft».

## Ограничения

- Dota2ProTracker и Dotabuff блокируют прямое чтение страниц ботами, поэтому их цифры берутся
  из поисковых сниппетов, а подробности — с Liquipedia и OpenDota-сайтов. Полную таблицу меты
  скилл не видит.
- Полный разбор занимает примерно 30–60+ секунд (зависит от модели и нагрузки) — на один ход пика
  не успевает, для этого есть быстрый режим.
- `/dota-draft-pro` делает 10–20 поисков, поэтому её запускают до игры или после драфта, а не во время пика.
- Профили многих игроков в пабах скрыты — таких игроков скилл пропускает.
- Статистика — это тенденция, а не гарантия победы.

## English

A Claude skill that analyses Dota 2 drafts from a pick-screen screenshot using **current-patch** data
(it looks up the live patch and meta every time instead of trusting model memory).
*Fast mode* (incomplete draft or "fast"): 1–2 searches, top-3 picks for your slot plus the main threat.
*Full mode*: roles, lanes, timings, win conditions, threats, verdict, sources.
*`/dota-draft-pro`*: for pro matches - rosters/stand-ins, team form on the current patch, head-to-head,
player signature heroes and comfort picks, key matchups, verdict with confidence.
Install on claude.ai via **Customize → Skills → Upload a skill** with `dota-draft.zip` from Releases
(code execution and web search must be enabled), or `git clone` this repo into `~/.claude/skills/dota-draft` for Claude Code.
